# Licenças de assets

Por enquanto, todos os gráficos do jogo são placeholders criados em código. Os sons também serão sintetizados em código. O único asset de terceiros é a fonte pixel dos textos, registrada abaixo.

## Registro de assets

Cada asset externo adicionado no futuro deve ser registrado aqui.

| Asset                  | Autor     | Fonte                                                                                                                    | Licença                   | Arquivo                                                                                                                                                                             |
| ---------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------ | ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Fonte "Press Start 2P" | CodeMan38 | [Google Fonts](https://fonts.google.com/specimen/Press+Start+2P), instalada pelo pacote npm `@fontsource/press-start-2p` | SIL Open Font License 1.1 | `node_modules/@fontsource/press-start-2p` (empacotada pelo Vite no build). Os glifos também são desenhados em tempo de execução num atlas de bitmap (fonte derivada, mesma licença) |

## Regra

Só entram assets com licença livre (CC0, CC-BY, etc.). Sempre registre o autor e o link da fonte na tabela acima, antes de usar o arquivo no projeto.
